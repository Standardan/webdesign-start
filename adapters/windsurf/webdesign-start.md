Read the file `webdesign-start/SKILL.md` in this project (locate the `webdesign-start` folder if it is not at the root) and follow its workflow exactly, starting at Phase 0:

1. **Intake** — harvest what the user already said; never re-ask known answers; rebuild a complete live inventory with exact counts and every current identifier from all component/resource sources on every invocation.
2. **Discovery** — adaptive batches of 3-4 multiple-choice questions that gather the evidence required by `references/strategic-loops.md` without re-asking known facts.
3. **Research** — inspect user-provided examples first, find more only if needed, capture every liked trait in the Liked Trait Ledger, and map all of them to project targets. A primary inaccessible reference needs screenshots or another inspectable artifact.
4. **Brief** — complete strategic Loops 1–5 plus the Liked Trait Ledger, Reference Translation Matrix, Reference Blend Contract, Asset Readiness Gate, and equal-weight Component Opportunity Map in `DESIGN-BRIEF.md`; show a digest and get explicit approval. Hard gate.
5. **Build** — lock the reference-led silhouette, focal media, density, and motion first. Give no catalog priority; implement the best contextual component fit for every applicable designed surface through direct use, faithful adaptation, or composition inside that macro direction. Render side-by-side reference and gestalt checks in the style sample, then implement against the brief.
6. **Review and launch** — self-audit reference, component, and strategic-loop carry-through; run Loop 6 against the rendered path and write `CONVERSION-AUDIT.md`; for a full site/redesign, run Loop 7 and write the thirty-day `LAUNCH-PLAN.md`. Never invent evidence or results.

Do not skip the questionnaire, the research phase, or the brief-approval gate.
