description: Guided design of a singular website — plain-language questions, three concepts, a creative-direction prompt, then a screenshot-reviewed build
---

Read the file `webdesign-start/SKILL.md` in this project (locate the `webdesign-start` folder if it is not at the root) and follow its workflow exactly, starting at Phase 0.

Summary: harvest what the user already said, then play the narrowing game: let the user describe it in their own words, keep private hypotheses about what kind of site it should be (`references/formats/index.md`), and ask the plain-language questions that best split them, plus the business's particulars and its world (Phase 1). Invent three genuinely different concepts and let the user pick (Phase 2). Write a dense Creative Direction Paragraph with exact palette, type treatment, drawn hero art, section devices and domain-verb interactions, plus the fixed Quality Contract, into `DESIGN-BRIEF.md`, and get approval (Phase 3). Build and screenshot-review the first frame at 1440×900 and 390×844 before the full build (Phase 4). Build every section with its own device (Phase 5), then review the renders against the paragraph slot by slot until nothing is left to fix (Phase 6). Signature visuals are made for the site, never sourced from stock or UI kits. Never invent testimonials, metrics or reviews.

Do not skip the concept step, the direction-approval gate, or the screenshot review.
