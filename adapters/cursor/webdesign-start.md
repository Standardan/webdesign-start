# /webdesign-start — Guided web design discovery & build

Read the file `webdesign-start/SKILL.md` in this project (if it is not at the project root, locate the `webdesign-start` folder — it may live in `.cursor/`, a `skills/` directory, or the repo root) and follow its workflow exactly, starting at Phase 0.

Summary of what you are signing up for: on every invocation rebuild a complete live inventory with exact counts and every current identifier from all component/resource sources. For a full site/redesign, execute all seven hard loops in `references/strategic-loops.md`: creative direction, conversion-critical section, motion, conversion copy, technical build plan, rendered-site conversion audit, and thirty-day launch plan. Run the adaptive discovery and real-site research, then persist Loops 1–5 plus the Reference Translation Matrix and Component Opportunity Map in `DESIGN-BRIEF.md`. Give no catalog priority: every designed surface uses the best contextual live-catalog lineage. Confirm the strategy and design in a rendered style sample, then finish with hard-gate audits plus `CONVERSION-AUDIT.md` and `LAUNCH-PLAN.md`. Never fabricate evidence, customer language, metrics, or experiment results.

Do not skip the questionnaire, the research phase, or the brief-approval gate — the entire value of this command is removing ambiguity before code is written.
